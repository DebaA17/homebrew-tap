# Security Policy

## Reporting a Vulnerability

We take the security of our tools and formulae seriously. If you discover a security vulnerability in any formula or its underlying binary, please do not open a public issue. 

Instead, please report it privately:
- Submit a report through the **Security** tab of the respective tool's repository on GitHub (e.g., [CVE-scanner-cli](https://github.com/DebaA17/CVE-scanner-cli/security/advisories) or [omnifetch](https://github.com/DebaA17/omnifetch/security/advisories)).
- Alternatively, reach out to the owner directly via the contact information on their GitHub profile.

### Supported Versions

Only the latest release of each formula in this tap is actively supported and receiving security updates. If you are experiencing a vulnerability, please ensure you have upgraded to the latest version by running `brew upgrade <formula>`.

### Response and Remediation

We will make every effort to acknowledge receipt of security reports within 48 hours and provide a remediation timeline. Once a fix is verified, a new release will be published and the corresponding formula in this tap will be bumped immediately.
